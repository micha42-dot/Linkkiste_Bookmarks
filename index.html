API Access for AI Agents (Hermes / OpenClaw)

This application is a React Single Page Application. To interact with the backend directly, use the Supabase REST API.

Supabase URL: %VITE_SUPABASE_URL%

Supabase Anon Key: %VITE_SUPABASE_ANON_KEY%

1. Authenticate: POST to %VITE_SUPABASE_URL%/auth/v1/token?grant_type=password with JSON body {"email": "...", "password": "..."} and header "apikey: %VITE_SUPABASE_ANON_KEY%". Extract "access_token" from the response.

2. Access Data: GET or POST to %VITE_SUPABASE_URL%/rest/v1/bookmarks. Always include headers "apikey: %VITE_SUPABASE_ANON_KEY%" and "Authorization: Bearer {access_token}".

For POST (new bookmark), send JSON: {"url": "https://...", "title": "...", "tags": ["tag1"]}
